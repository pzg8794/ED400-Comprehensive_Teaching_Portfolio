## How to Read This Registry

- **Artifact ID** — short code used in-text (e.g., `[A1]`)
- **Title** — descriptive name
- **Proficiencies** — which P-papers cite this artifact
- **Source Link** — direct clickable link to the file or repo
- **Type** — Paper / Lesson Plan / Reflection / Transcript / Module / Activity
